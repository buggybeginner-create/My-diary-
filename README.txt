MY DIARY - setup (free, Rs 0)

1. HOSTING (pick one)
   A) Netlify Drop (easiest): open app.netlify.com/drop, sign in free, drag this whole MyDiary-App folder onto the page. You get a https link.
   B) GitHub Pages: make a free repo, upload these files, Settings > Pages > deploy from main branch.
   C) Cloudflare Pages: Workers & Pages > Create > Pages > Upload assets, drop the folder.
   Keep all files together: index.html, sw.js, manifest.webmanifest and the icons.

2. INSTALL
   iPad/iPhone: open the link in SAFARI > Share > Add to Home Screen.
   Android: open in Chrome > menu > Install app.
   Then use ONLY the home-screen app (it has its own storage, separate from the browser tab).

3. FIRST RUN
   In the app: Save & backup > create a backup file (or use Save backup to Files / Drive on iPad).
   To move old data: Export Backup in the old copy, then Restore from file in the new one.

4. UPDATING LATER
   Upload the new index.html over the old one (same folder). The app picks it up next time it opens online.
